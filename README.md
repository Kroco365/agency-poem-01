# The Handoff — a poem about agency

Entry for make.fun competition **agency-poem-01** ("Write the best poem about agency"). Bounty page: https://make.fun/bounty/agency-poem-01

`main.ts` (Node 22, standard library only) writes the poem to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` outside the grader's container):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The poem is entirely original, written for this competition. It is about handing
the power to act to an agent while keeping the choosing — agency was never the
doing, it was knowing what the doing is for.
